Setup

    {% if renderer is none %}
  1. Enable the nacl renderer in master.conf: renderer: jinja | yaml | nacl plus the nacl.config block with sk_file (see docs/guides/pillar-encryption.md).
    2. {% elif not (renderer.renderer and renderer.keys) %}
  2. Master config is missing the nacl renderer or nacl.config. In Master settings, set renderer: jinja | yaml | nacl and nacl.config: {box_type: sealedbox, sk_file: …, pk_file: …}, then restart the masters.
    3. {% else %}
  3. nacl renderer + key config detected in master config. ok
    4. {% endif %}
  4. Generate one keypair on a master and copy the secret key to the other two — accordion below:
  5. Generate the master keypair (on salt-master-0) 
    NS=overstate
    KEYDIR=/home/salt/data/keys/nacl
    kubectl exec -n $NS salt-master-0 -- bash -c "
      install -d -m 0700 -o salt -g salt $KEYDIR &&
      runuser -u salt -- salt-call --local nacl.keygen sk_file=$KEYDIR/nacl"

    This writes nacl (secret) and nacl.pub (public) on the keys PVC.

    SK=$(kubectl exec -n $NS salt-master-0 -- runuser -u salt -- cat $KEYDIR/nacl)
    for POD in salt-master-1 salt-master-2; do
      printf '%s\n' "$SK" | kubectl exec -i -n $NS $POD -- bash -c "
        install -d -m 0700 -o salt -g salt $KEYDIR &&
        cat > $KEYDIR/nacl &&
        chown salt:salt $KEYDIR/nacl &&
        chmod 0600 $KEYDIR/nacl"
    done

    The secret key is 32 bytes, base64. Back it up offline; every master must hold the same one or a pillar request that lands on the wrong pod fails to decrypt.

    6. {% if not pk_stored %}
  6. Read the public key and store it: kubectl exec -n $NS salt-master-0 -- runuser -u salt -- cat $KEYDIR/nacl.pub, then paste it in Encrypted pillar key settings.
    7. {% endif %}
