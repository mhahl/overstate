# Overstate v3 — Pillar explorer + operator-speed UX

Status: **Final** (accepted by owner; staged implementation still needs
separate approval).

Scope note: this record covers the v3 decision set only. Accepting it does
not approve implementation or any later stage; each stage returns separately.

## Settled

- D1 — Pillar scope: explorer + audited actions. Per-minion rendered pillar,
  minion-vs-minion diff, snapshot history, `saltutil.refresh_pillar` /
  `saltutil.sync_all` as job presets. No file writes; the git checkout stays
  the source of truth (files.py remains read-only).
- D2 — UX focus: operator speed. Command palette, bulk minion actions,
  saved-job shortcuts. No new JS framework; DaisyUI + Tailwind only.

## Settled (continued)

- D3 — Pillar secrets: full values visible to authenticated users.
  No key-name redaction heuristics, no sensitivity notice (removed per
  owner request after acceptance).

## Open

- D4 — Snapshots: last 10 per minion, captured only on explicit action.
  No background fleet-wide refresh.

## Open

- D5 — Diff: minion vs. minion, against live values or snapshots
  (single code path; no self-history diff view).

## Open

  pages (Alpine overlay; new snapshot-search endpoint for minions).

- D7 — Bulk actions: selection compiled to a glob target, shown for

## Open
