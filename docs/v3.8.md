## Settled

- D1 — Enrollment method: guided-manual steps (install, configure,
  start, accept, verify). No SSH bootstrap from the app.
- D2 — Master hostname: database-backed setting editable on the server
  Settings page, defaulting to the detected FQDN (admin corrects it
  there when detection doesn't match the minion-facing master).
- D3 — Key accept: deep-link to the Keys page (wizard shows the live
  pending count); no duplicated accept flow.
- D4 — Placement: "Onboard minion" button on the Minions page plus a
  link from the Keys pending empty state; no sidebar entry.
